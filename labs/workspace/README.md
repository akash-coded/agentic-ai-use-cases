# Workspace

Your solutions live here. `labctl start <ID>` copies a starter into `workspace/<ID>/solution.py`.

This directory **is** tracked by git. If you fork the repo and commit your solutions, the
[labs workflow](../../.github/workflows/labs.yml) grades them on every pull request and comments the
result — so you get the same feedback locally and in CI.

Alongside each solution, write a `DECISION.md`. Every lab's Learn phase asks you to make one decision
before you write code; recording it is what turns a set of finished exercises into an
[artefact trail](../PATHWAY.md#the-pdlc-thread) you can show someone.

```
workspace/
└── AGL-01/
    ├── solution.py     ← your code, graded
    └── DECISION.md     ← the decision you made, and why
```
