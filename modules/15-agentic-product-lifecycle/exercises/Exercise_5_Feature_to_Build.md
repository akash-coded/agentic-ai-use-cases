# Exercise 5 — Match the feature to its build

*Format: matching · Time: 5 minutes · Answer in the chat*

## Recap

Four builds sit on a spectrum of autonomy. Only two of them use a model. Naming the build for a feature is what takes rules out of the AI conversation.

| Build | What it is | Model? |
|---|---|---|
| Rule | fixed logic | no |
| Workflow | fixed steps | no |
| Assisted | model suggests, person decides | yes |
| Agentic | model decides across tools | yes |

## The exercise

Match each feature to its build. Each build is used at least once.

**Features:**

1. Notify a passenger when their gate changes
2. Choose the best of several rebooking options for a delayed flight
3. Refund a cancelled booking inside a fixed policy, no judgement
4. Rebook a multi-leg international trip across partner airlines end to end

**Builds:**

- w. Rule or workflow (no model)
- x. Assisted (model suggests, person decides)
- y. Agentic (model decides across tools)

**How to answer.** Type your matches, for example `1-w 2-x 3-w 4-y`.
