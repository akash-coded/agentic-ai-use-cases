# Exercise 3 — Spot the ceiling that is wrong

*Format: single-select plus a follow-up · Time: 6 minutes · Answer in the chat*

## Recap

Two questions place any action on the ladder: can it be taken back, and does it hurt if wrong. The whole agent runs at the **lowest** level any single action allows.

| | Does not hurt | Hurts |
|---|---|---|
| **Irreversible** | L2 act and tell | L1 approve first |
| **Reversible** | L3 act alone | L2 act and tell |

## A colleague's scoring

They scored the actions for a **baggage-claim agent** and wrote its ceiling underneath.

| The action | Reversible? | Hurts? | Level |
|---|---|---|---|
| Read the baggage record | Yes | No | ? |
| Look up the compensation policy | Yes | No | ? |
| Send the passenger an update | No | No | ? |
| Pay interim expenses to the passenger's card | No | Yes | ? |
| **Their written ceiling** | | | **L2 act and tell** |

## The exercise

**3a. Is the ceiling correct?**

- a. Correct
- b. Wrong

**3b. If it is wrong, which single fact makes it wrong?**

- c. Sending an update cannot be taken back
- d. Paying interim expenses is irreversible and hurts if wrong
- e. Looking up a policy could return an outdated policy
- f. Reading the record is the only fully safe action

**How to answer.** Type both, for example `3a-b 3b-d`.
