# Exercise 5 solution — Match the feature to its build

## Answer

**1-w** Rule  ·  **2-x** Assisted  ·  **3-w** Rule  ·  **4-y** Agentic.

## Teaching point

Most of a backlog is not agentic. Naming the build for each feature is what takes rules out of the AI conversation.

## Feature to build

| Feature | Build | Why |
|---|---|---|
| 1. Notify on a gate change | Rule / workflow | a fixed trigger fires a message, no model |
| 2. Choose the best rebooking option | Assisted | a model ranks, a person picks |
| 3. Refund inside a fixed policy | Rule / workflow | fixed rules, deterministic, no judgement |
| 4. Rebook a multi-leg trip end to end | Agentic | a model decides across several tools |

## The point to land

Two of the four features need no model at all. In a real backlog that share is often higher than the room expects, and those rows leave the agentic work entirely. Shrinking the list of things that actually need an agent is the most useful thing a PM can do with this framework.
