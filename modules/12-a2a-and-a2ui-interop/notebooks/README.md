# A2UI Hands-on — Final Day

Two runnable notebooks for the A2UI session, anchored on the TravelMind airline agent (PNR `JX48Q2`, `us-east-1`).

## Files

| File | What it is |
|---|---|
| `Notebook_1_A2UI_through_Strands.ipynb` | Build A2UI on a Strands agent: payload, validator, tool, agent, approval, audit, admin |
| `Notebook_2_A2UI_with_AgentCore.ipynb` | Same agent on AgentCore: Runtime, Identity (roles), Policy (gate), Observability |
| `travelmind_admin.py` | Streamlit admin view, generated by Notebook 1 step 8 |
| `requirements.txt` | Pinned dependencies |

## Setup (once)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name a2ui --display-name "A2UI"
```

## Run order

1. Open `Notebook_1_A2UI_through_Strands.ipynb`, run all cells top to bottom.
2. Launch the admin view it generated:
   ```bash
   streamlit run travelmind_admin.py
   ```
3. Open `Notebook_2_A2UI_with_AgentCore.ipynb`, run all cells top to bottom.

Both notebooks run fully offline by default. Live Bedrock and AgentCore deploy paths are gated behind flags and clearly marked.

## Going live (optional)

| To enable | Do |
|---|---|
| Live agent in Notebook 1 | Set `CONFIG["run_live_agent"] = True`, configure AWS creds, enable Claude Haiku 4.5 model access in `us-east-1` |
| Deploy to AgentCore | Follow the `agentcore configure` / `agentcore launch` block in Notebook 2 step 2 (needs Docker or Finch + an IAM execution role) |

## Config facts that bite

- Model id `us.anthropic.claude-haiku-4-5-20251001-v1:0` is an inference profile. A bare model id throws `ValidationException`.
- IAM action is `bedrock:InvokeModel` (covers the Converse API). There is no `bedrock:Converse` action.
- The AgentCore starter toolkit defaults to `us-west-2`; set the region to `us-east-1` to match TravelMind.

Verified against: a2ui.org (v0.8 stable), strands-agents 1.42.0, bedrock-agentcore 1.14.0, AgentCore GA (Oct 2025) and Policy preview (Dec 2025).
