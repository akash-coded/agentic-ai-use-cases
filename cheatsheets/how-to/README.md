it and operate it need their own recipes — not a simplified version of the engineering one.

## The guides everyone should read, whatever their role

| Guide | Why |
| --- | --- |
| [Build a golden set from real tickets](business-analysts/build-a-golden-set.md) | It is the specification. Engineers build to it, QA gates on it, PMs write criteria from it |
| [Write acceptance criteria](product/write-acceptance-criteria.md) | Rates on a named set, not pass/fail on a case |
| [Run a demo that builds trust](product/run-a-demo-that-builds-trust.md) | Everyone demos eventually, and most demos spend trust rather than build it |
