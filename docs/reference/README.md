## If you want to teach from this

It is MIT licensed — see [`CITATION.cff`](../../CITATION.cff) for the citation format.

The [training frameworks playbook](training-frameworks-playbook.md) explains *why* the curriculum is
sequenced the way it is: outcomes written before content, assessment designed second, and every
abstraction preceded by the thing it abstracts.

A facilitator kit — timings, discussion prompts, and where people predictably get stuck — is
[on the extension roadmap](../extension-roadmap.md#phase-4--team-adoption--beyond-the-individual-learner)
and open to contribution.
