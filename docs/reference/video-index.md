## What a walkthrough will cover

Each recording follows the module's own sequence — the same order given in that module's README — and
concentrates on the parts a written page handles badly:

- Console work, where the click path matters ([Modules 03](../../modules/03-bedrock-agents/), [04](../../modules/04-agent-builder-and-knowledge-bases/), [11](../../modules/11-bedrock-agentcore/))
- Live debugging, where the value is in the wrong turn before the right one
- Trade-off discussions, where the reasoning matters more than the result

## In the meantime

The written material is designed to stand alone. Each module README gives you the exact order to work
through, and the [LLD pages](../architecture/lld/) explain the mechanism behind each one.
